# 彬少剧场 · 双面剧本

一个纯前端、零依赖的文字推理剧场。两个完整剧本，以"屏幕前的观察者"视角，陪彬少和朋友们走进两个故事。

## 怎么开始

**方式一（最简单）**：直接双击 `index.html`，用浏览器（Chrome / Edge / Safari）打开即可。

**方式二（本地服务器）**：
```bash
cd binshao_theater
python -m http.server 8642
# 浏览器访问 http://127.0.0.1:8642/
```

**手机端**：同一局域网内用手机浏览器访问 `http://<电脑IP>:8642/`，或直接把整个文件夹传到手机后用浏览器打开 `index.html`。已适配竖屏布局与触屏操作。

## 两个剧本

### 剧本 Ⅰ《雷雨山庄杀人事件》（本格推理 · 3 种结局）
暴雨封路的山顶别墅，密室中的尸体。彬少带你逐一录口供、搜书房、拼时间线，
终幕是奎因式的"挑战读者"——三个问题，最后一个由你来答。
- 攻略提示：多和每个人说话，多检查角落，线索笔记（📓）会记下一切
- 结局：S「雨停之后」 / A「迟来的真相」 / F「被冤枉的人」
- 全线索 20 条，答错会在终幕给出提示，F 结局可从检查点重来

### 剧本 Ⅱ《深渊回响》（古城探险 · 4 种结局）
一张爷爷的地图，一座沉入地底三百年的古城，一口会回答问题的巨钟。
路线抉择、石门谜语、火盆机关、营地夜谈——每个人的选择都在积累 勇气 / 智慧 / 羁绊。
- 结局：S「回响长鸣」 / A「带回的声音」 / A「黄金的重量」 / F「沉默的钟」

## 系统功能

- 对话打字机、自动播放（⏩）、对话记录（📜）
- 推理笔记：线索收集 / 状态（勇气·智慧·羁绊）/ 成就（📓）
- 章节自动存档 + 手动存档，标题画面可"继续冒险"
- Canvas 电影特效：雷电、 blackout、记忆闪回、崩塌、洪水、钟鸣、金色结局等十余种"特效过场"
- WebAudio 程序化配乐与音效（雷声、心跳、钟声、环境音乐），无任何外部资源
- 人物图鉴、8 项成就、设置（文字速度 / 音效 / 特效开关）

```
js/characters.js    角色数据 / 成就 / 设置

js/story2.js        剧本Ⅱ《深渊回响》
js/main.js          标题画面与入口接线
```

## 想自己写剧本？

在 `js/story2.js` 顶部有一套现成的 DSL：
- `S('bin','台词','shock')` 说话　`N('旁白')` 旁白
- `BG('hall')` 场景　`BGM('tense')` 音乐　`FXE('thunder')` 特效
- `ENT('wei','L')` / `EXT('wei')` 角色上下场
- `CLUE('id','名称','描述','🔍')` 线索　`STAT({bond:1})` 数值
- `CHOICE('提问',[OPT('选项','跳转标签',{stat:{...}})])` 选项
- `QZ('问题',['A','B'],正确索引,'答错跳转','提示')` 推理问答
- `LBL('x')` / `GO('x')` / `BR([{if:'旗标',goto:'x'}])` 分支
- `CG('章节','标题')` 章节卡　`END(...)` 结局
